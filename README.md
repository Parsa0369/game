# PersianFPS

نمونه‌ی اولیه‌ی قابل‌بازی برای Godot 4.

## اجرا
1. در GitHub Desktop روی **Fetch origin** و سپس **Pull origin** بزن.
2. Godot 4 را باز کن.
3. در Project Manager روی **Import** کلیک کن و فایل `project.godot` را از پوشه‌ی محلی این مخزن انتخاب کن.
4. پروژه را باز کن و با F6/F5 اجرا کن.

## کنترل‌ها
- WASD: حرکت
- ماوس: نگاه کردن
- کلیک چپ: شلیک
- Space: پرش
- R: پر کردن خشاب
- Esc: آزاد کردن ماوس
- کلیک راست: گرفتن دوباره‌ی ماوس

این نسخه پایه‌ی اولیه است؛ حالت‌های بازی، بات‌های هوشمند، نقشه‌های بیشتر و بخش آنلاین در مراحل بعدی ساخته می‌شوند.
